## 운영 원칙
- 키 없는 파일(1·3·5·8·16) → 클라우드 자동 수집 → data-vault `raw/` + `catalog.csv`
- 키·로그인 필요(2·6·7·10·12·13·15·18) → PC에서 스크립트 실행, 키는 `.env`만, 결과를 data-vault에 올림
- 100MB 넘는 파일 → PC 외장 폴더 또는 LFS, catalog에 위치·sha256만
- 클라우드 접속 허용 추가가 필요하면 세션에서 요청(환경 설정 → 허용 호스트)
